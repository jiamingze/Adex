四个独立业务服务：模块、数据所有权、调用边界

前端（Web / Desktop / Mobile / 设备代理）只调用 adex-app 公网 API；其他三个后端服务走内部鉴权接口，服务间不共享写表权限。

adex-app

Java · Spring Boot · ToC 产品入口
  • Gateway、Identity、会话消息、权限
  • L2 原始消息/摘要、L3 长期记忆
  • Knowledge / RAG 接口、Workspace / OSS
  • UI Schema、大卡、引用、SSE/WS
  • Notification Worker / 账务和额度
  • 提供 Context API 给 Agent
DB Owner：用户 / 会话 / Memory / 文档 / 通知

adex-agent

Python · FastAPI · 统一智能运行引擎
  • 请求语义路由与任务候选解析
  • Context Builder（读取 L1/L2/L3）
  • LLM Gateway、Planner / Replan
  • Skills Loader、Tool Orchestrator
  • 交互/后台两类 Worker 与预算
  • 输出流、大卡提议、Checkpoint 引用
DB Owner：Agent 配置 / 模型调用元数据

adex-automation

Java · Spring Boot · 持久运行控制
  • Task / Run / Step / Workflow
  • Schedule / Occurrence、Misfire
  • Monitor、Polling、Webhook 观测
  • Subscription、Rule Engine、Goals
  • 分布式领取、Lease、Epoch、恢复
  • 领域事件、Outbox、通知意图
DB Owner：任务 / 调度 / 监控 / 规则 / 事件

adex-tools

Python · FastAPI · 能力与运行入口
  • Tool / Skill Registry、MCP
  • 第三方 Connector 与 OAuth Vault
  • WebSearch、天气、酒店等工具
  • 受控 Browser / Code Runner 适配
  • Schema、权限、Rate Limit
  • Effect Key、副作用回执与核对
DB Owner：工具目录 / 凭证引用 / Effect

基础设施：不是新的业务微服务

主存储与索引异步同步；不同服务共用 PostgreSQL 实例时，也应采用独立 Schema 和 DB Role。

PostgreSQL · 权威数据

R / W 用户、会话完整消息、L2/L3 Memory、Task/Run、Schedule、Tool Effect、通知。跨服务不可直接写他人的 Schema。

Redis · 热缓存与 L1

R / W 最近上下文、工作态、限流、可重建缓存、短期唤醒信号。不能替代任务/消息权威数据。

Elasticsearch · 可重建索引

R + 异步 W 聊天全文检索、RAG Chunks、L3 记忆检索、复杂事件候选。它不是原始消息数据库，初期可用 PG FTS/pgvector 替代。

OSS / S3 · 大对象

R / W 附件、截图、文档、生成作品、工具执行证据；PG 保存 Object Ref / 版本 / 权限。

决策规则：任何新功能先看执行生命周期

实时路径

客户端 → App → Agent →（Tools / 模型）→ App → 客户端

普通聊天、快速联网问答、卡片展示不创建 Automation Run。App 负责权威消息和 UI，Agent 负责智能判断。

持久路径

客户端 → App → Agent（解析）→ Automation（持久化）→ Agent Worker（执行）→ App

定时、长期监控、后台工作、浏览器交易、断点恢复需要 Automation 的 Task/Run、租约和事件。

三层记忆数据流

L1 Redis/Runtime → L2 PostgreSQL 会话/摘要 → L3 PostgreSQL 长期记忆 + ES 候选

Agent 通过 App Context API 获取授权快照。L3 需要审查、版本、删除；Automation 的 Checkpoint 与用户记忆分开。

通知不是聊天流

Automation 产生 notification.requested → App.Notification 持久消费 → Push / 站内信

聊天 Token 和任务进度用 App SSE 转发；离线 Push 有独立重试、免打扰、幂等和渠道限流。
