# Roadmap / 路线图

This is a direction, not a release promise. / 以下是方向，不是上线承诺。

## Current foundation

Shared Web/iOS UI; four service domains; chat/search/memory; durable automation; private files and versioned artifacts; provider adapters; isolated runners and recovery tests. See actual [evidence](docs/ACCEPTANCE_EVIDENCE.md).

## Next priorities

- Real Google OAuth consent/verification and APNs device delivery acceptance; native OAuth handoff, richer mailbox/calendar delta subscriptions and reconciled Run presentation.
- Physical iOS regression coverage: photo upload, speech recognition, keyboard and weak-network recovery.
- Stable hosting and external access with documented operating costs and provider region compatibility.
- Broader schedule language, improved accessibility and mobile interaction quality.
- More reproducible media adapter tests and clearer per-capability entitlement reporting.
- Fresh-install verification and maintained English/Chinese documentation.

## Beyond the current scope

App Store distribution, enterprise collaboration, payment/booking, generalized desktop agents and multi-region availability require separate design and acceptance work.
